How it works

From install to first summary in minutes

  1. Install

    Use published builds for Edge and Firefox. For Chrome, Brave, Opera, Vivaldi, Ulaa, and other Chromium browsers, follow the temporary install flow in Install Guide.

  2. Pick a chapter

    Open a supported site. The extension detects chapters and adds inline controls.

  3. Enhance or summarize

    Click Enhance for polished text or Summarize for quick context. Long chapters are chunked safely.

  4. Export anytime

    Export your library to JSON for safekeeping and re-import later. No cloud dependency.

FAQ

Answers at a glance

💡 What is Ranobe Gemini?

Ranobe Gemini is a browser extension that enhances machine-translated web novels and fanfiction — improving readability, grammar, and flow while keeping the original story intact — using the AI provider you choose. It also provides summaries, story chat, and site-aware content processing. It started as a Gemini-only tool, which is where the name comes from; it is no longer limited to Gemini.

🤖 Which AI providers can I use?

Three, selected in Settings: Google Gemini, any OpenAI-compatible endpoint (so most hosted providers and gateways work by pointing at their base URL), and Ollama running locally on your own machine. You can also configure a fallback provider that takes over when the primary one fails or rate-limits.

🔑 Do I need an API key?

For a hosted provider, yes — and it stays on your device. Add your free Gemini key from Google AI Studio, or an OpenAI-compatible key, in the popup Settings tab. Backup keys and rotation are supported for rate limits. With Ollama you need no key at all: the model runs locally and nothing leaves your machine.

🌐 Which sites are supported?

Currently supports: Archive of Our Own (AO3), FanFiction.net (desktop + mobile), Ranobes, ScribbleHub, NovelBin, NovelArrow. WebNovel is temporarily disabled while we refine it. More sites may be added based on user requests.

💾 How does content caching work?

Enhanced chapters are automatically cached for 7 days. When you revisit a chapter, the cached version loads instantly. You can regenerate fresh content or delete the cache using the buttons in the enhanced banner.

📚 How do I import or export?

Popup → Library tab → Export downloads a JSON; Import restores it later. No cloud dependency. You can also use the backup features in the Advanced tab for automatic backup rotation.

🔄 How do I toggle original vs enhanced?

After enhancement, a banner appears at the top letting you switch between original and enhanced, or delete cached copies. Use the Show Original or Show Enhanced buttons.

⚙️ Which Gemini model should I pick?

Gemini 3 Flash Preview is the default and right for most users; Gemini 3 Pro Preview is highest quality with a much larger context window but slower; 2.5 Flash is the built-in fallback if a request fails. Once your API key is saved this list is replaced with the live model list from Google, so newer models show up without an extension update.

🔧 What if enhancement fails?

Test your key in the popup (Settings → Test Key), enable chunking for long chapters under Advanced settings, lower temperature to 0.3, and retry. Check console (F12) for detailed errors. Report persistent issues on GitHub.

🎨 What do advanced parameters do?

Temperature controls creativity (lower = consistent, higher = creative). Top-P limits token diversity. Top-K sets maximum tokens per step. Max Output sets response length. Use defaults unless you understand these.

📋 What are Custom Prompts?

Custom prompts let you control how the AI processes content. Enhancement Prompt improves translation quality, Summarization Prompt creates summaries, Permanent Prompt adds global instructions. Reset to defaults if unsure.

💰 Is it free?

The extension is open-source and free, and there is no account and no subscription. What you pay is whatever your chosen AI provider charges — nothing if you run Ollama locally, and nothing within Gemini's free tier. Check Google AI pricing for its rate limits.

💬 What is Story Chat?

A conversation about what you are reading, in the popup's Chat tab. It can draw on the chapter you have open and on the running chronicle of what you have already read, and you control how much history it carries — configured under Chat Settings in Library Settings. Useful for "wait, who was that again" without scrolling back forty chapters — or being spoiled by a wiki.

📥 Can I enhance several chapters at once?

Yes — the chapter queue processes them in the background while you keep reading, and can be paused, resumed, or cancelled at any point. Long chapters are chunked automatically, so a queued 10,000-word chapter is not one oversized request.

📖 How does the Library work?

The Library tab tracks all novels you've read, showing current novel details, suggestions, and complete reading history organized by website. Export/import your library as JSON for backups. Each novel stores metadata like characters, relationships, genres, reading status, and progress.

🕵️ What is Incognito Mode?

Incognito Mode pauses library tracking so visiting chapters doesn't update your reading history. Toggle it from the popup or Library Settings with a configurable auto-expiry (30 min, 1 hour, 2 hours, or manual). Your existing library data is never affected.

🔗 What are Custom Content Boxes?

Custom Content Boxes let you define your own CSS class names, display names, and styling for special content types (e.g. a custom game-stat box style). Configure them in Library Settings with a live preview. They complement built-in types like Author Notes, Game Stats, and Flashbacks.
