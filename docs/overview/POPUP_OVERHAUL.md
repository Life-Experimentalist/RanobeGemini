# Phase 14: Popup UI Overhaul

## Objective
Modernize and redesign the extension popup menu so that it accurately reflects the latest library settings and library page features. The popup has fallen out of sync with the application capabilities.

## Motivation
- The library has evolved significantly with new filter tags, sync options, and a sleeker UI.
- The popup is currently out-of-sync visually and functionally.
- Redesigning it ensures users have a unified experience regardless of whether they interact with the main library page or the popup.
